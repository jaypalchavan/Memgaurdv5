Stage 1: Multi-Vector Telemetry Ingestion Layer
Latency: ~2.4ms

The ingestion layer captures system activity across multiple heterogeneous vectors without kernel destabilization:

Windows Sysmon Operational Log

Parses Microsoft-Windows-Sysmon/Operational channel using XML stream deserialization for Process Create (Event 1), Network Connect (Event 3), and Driver/Image Loads (Event 7).

PsUtil Low-Level Kernel Hook

Queries Windows NT executive process tables to extract executable path, PID, working memory RSS, security context, and parent PID.

Cross-Platform EDR Telemetry REST API

Exposes POST /api/telemetry/report enabling remote agents running on Linux servers, macOS workstations, and Android devices to report events seamlessly.
